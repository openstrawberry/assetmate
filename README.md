## 🚀 Overview
AssetMate is a simple and efficient tool designed to make adding assets to your Flutter project seamless and hassle-free its open source and free for anyone to use.

## ✨ Features
- 🔍 **Quick Asset Addition** – Easily add assets to your project.
- 🔗 **Seamless Flutter Integration** – Works effortlessly with Flutter projects.
- just select your project folder and automatically it will be imported to your pubspec.yaml

## 🏗️ Tech Stack
- **Technology:** Flutter

## 📦 Installation
```bash
git clone https://github.com/txorav/assetmate.git
cd assetmate
```
### Setup
```bash
flutter pub get
flutter run
```

## 🛠️ Usage
1. **Add Assets** – Quickly add assets to your Flutter project.
